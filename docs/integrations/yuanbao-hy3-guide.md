# 腾讯元宝网页端 Hy3 Python 学习辅助指南

## 适用场景
面向刚开始学 Python 字典的高中生，通过元宝网页端的 Hy3 模型，
把"自己写代码 → 找 AI 优化 → 搞懂新知识点"串成一个学习闭环，
解决上课听懂了、但自己写代码时总漏细节，没有思路的问题。
## 前置要求
- 有元宝账号（微信扫码就能登，随时可用，无需启动资金，免费）
- 刚学完 Python 字典的基础用法
  （知道用 `{}` 创建字典、会用 `for` 循环遍历、知道用 `dict[key]` 存值）
  ## 操作步骤

### 1. 切换到 Hy3 模型
打开元宝网页端（https://yuanbao.tencent.com），
在输入框附近找到模型选择按钮，点一下选「Hy3」。
我选的是深度思考模式，内容经过模型自己推演，准确率更可靠。<img width="1044" height="659" alt="腾讯元宝hy3接入" src="https://github.com/user-attachments/assets/8266a4e2-f2ae-4b3a-9164-142c567f9856" />
### 2. 提交初版代码和优化需求
我将自行编写的、未处理大小写与标点的词频统计初版代码粘贴至输入框，
发送了如下需求：
> 我是高中生，刚学Python字典，这是我写的词频统计代码，能不能帮我改改，加上忽略大小写、去掉标点的功能，再告诉我你改了哪，为啥改呀？

（注：原始截图因操作失误丢失，但交互逻辑可复现，优化后的代码与下文一致）

### 3. 看优化结果和知识点解释
Hy3返回了优化后的代码，并逐行解释了新增逻辑：
- 使用`str.lower()`方法将所有单词转为小写，解决"The"与"the"被判定为不同词的问题
- 通过字符串切片或正则表达式过滤单词前后的标点（如逗号、句号），避免标点干扰统计结果

我当时重点消化了这两处修改的逻辑，刚好填补了我之前写代码时忽略的真实文本处理场景。
✏️ 改这里：把"刚好填补了我之前写代码时忽略的真实文本处理场景"换成你当时的真实感受，比如"我之前一直纳闷为啥统计出来的结果里'the'和'The'是两个数，看完解释才反应过来原来差在这"

## 学习心得
我写初版词频统计时，只想着用字典把单词存进去计数，
完全没考虑真实文本里的大小写混乱和标点干扰，
导致统计结果又脏又不准。

通过让 Hy3 帮我优化，我不仅拿到了能跑的正确代码，
更重要的是搞懂了"为什么原代码不够好"——
这种"先自己写一版 → 再找 AI 改 → 再对照学"的流程，
比直接看课本例题印象深得多，因为我是在解决自己在实操过程中遇到的真实问题，而不是在背标准答案。

另外撰写本指南时我因误操作丢失了原始截图，原本有些懊恼，但重新梳理交互逻辑的过程中，我对`lower()`方法和标点过滤的作用反而理解更深了，因为我是一名高中生，第一次参加腾讯犀牛鸟计划，我原来也没有做项目的经验，忘记了在工作的过程中要留痕，我在以后的工作中会及时留痕，感谢腾讯犀牛鸟计划提供的机会。

- 元宝网页端Hy3模型日常对话免费开放，无需配置API Key即可使用
- 简单代码优化需求建议使用「快速思考」模式，响应速度更快；复杂逻辑问题可开启「深度思考」模式获取更详细的推导过程
- 生成的代码需自行验证运行效果，避免直接照搬未理解的代码片段
